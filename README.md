# Mya Bot Showcase

Quero fazer um Site para o meu Bot do Discord, chamada Mya. Quero que o Site seja prático, sem muita poluição visual, quero que seja a dinâmica do Site da Bot Ayko e da Bot Loritta. Quero que tenha um visual bonito e que combine com a estética da personagem Mya, que vou te mandar junto com os arquivos do bot para você ter uma ideia do que tem para por no Site.
